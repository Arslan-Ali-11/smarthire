SmartHire uses the Google Gemini API (free tier) as its primary AI engine for resume parsing, scoring, and question generation. If the Gemini API hits its rate limit, the system automatically falls back to the Groq API (also free). You can also use Ollama with a local model for offline development.

SmartHire supports PDF and DOCX file formats. Files are limited to 5 MB. The system uses PyMuPDF for PDF extraction and python-docx for Word documents to ensure accurate text parsing.

When an applicant submits their resume, the AI parses it into structured fields (skills, education, experience, projects) and compares them against the job description and required skills. It then assigns a score from 0 to 100 with a short explanation highlighting matching skills and identifying gaps.

Applicants don't see their raw match score — that's only visible to recruiters. However, applicants do receive AI-generated feedback on how to improve their resume for the specific role they applied to, helping them strengthen future applications.
